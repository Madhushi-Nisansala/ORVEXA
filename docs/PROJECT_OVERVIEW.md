# Project Overview

ORVEXA transforms everyday information into understandable, trustworthy, and actionable intelligence. Initial users include students, families, professionals, and small businesses in Sri Lanka, with English, Sinhala, and Tamil support planned.

## Phase 1 boundary

This phase establishes the repository, backend and frontend entry points, local configuration, and documentation. It does not implement user accounts, analysis, persistence, uploads, or external provider integrations.

## Product principles

- Explain uncertainty and distinguish facts from interpretations.
- Treat user content as private and untrusted input.
- Require confirmation before consequential actions.
- Design for accessibility and multilingual text from the foundation.
